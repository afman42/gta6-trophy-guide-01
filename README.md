# Leonida Ledger — GTA 6 Trophy Guide

Offline, open-source trophy guide and tracker for Grand Theft Auto VI (PlayStation 5): all 55 official trophies with guides in our own words, a checklist saved in the browser, roadmap to the platinum, missable flags, filters and a spoiler setting.

Run it with node serve.ts, then open http://localhost:8080

Built for the make.fun bounty gta6-trophy-guide-01. Screenshots of the guide live in the competition entry bundle.
