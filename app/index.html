    Sources & honesty note

    Every trophy's name, description and grade is the official PlayStation 5 list, as published by Exophase and PSNProfiles; PSNProfiles also supplied the progress target where a trophy has one. Each guide is written in this guide's own words from that official description. Where a description does not pin down a place or a step, the guide says so plainly — “not yet checked in the game” — instead of inventing a location.
